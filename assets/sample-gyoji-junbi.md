# 行事の準備計画・役割分担（練習用）

**この資料は練習用に書き下ろした架空の内容です。実在の学校・学年・児童とは関係ありません。**
ほとんどの項目が教師の指示ですでに埋まっていて、子どもが決める欄がほぼ無い形をわざと残してあります。

## 学芸会 準備計画（抜粋）

| 項目 | 内容 | 決めた人 |
|---|---|---|
| 演目 | 学年ごとに教師が指定 | 教師 |
| 配役 | 教師が名簿順で仮決定、希望は参考程度 | 教師 |
| 台本 | 教師が用意したものをそのまま使用 | 教師 |
| 大道具・小道具 | 教師が発注、児童は色塗りのみ担当 | 教師 |
| 練習スケジュール | 週3回、教師が時間割に組み込み | 教師 |
| 進行の順番 | 教師が学年順に決定 | 教師 |
| 開会・閉会の言葉 | 代表児童が読む原稿を教師が作成 | 教師 |
| 当日の係 | 教師が名簿順に割り振り | 教師 |

児童が最終決定に関わっている項目は、この一覧の中に一つもありません。
